A deadpan one-star review of an everyday essential nobody can switch off:
the sun. Filed in earnest, like a real complaint, against a thing that
cannot be fixed — and the turn lands in the last few words, where the
reviewer discovers that management cannot help either.

The entry, one line, 142 characters:

> One star. The sun turns up uninvited every morning, stares straight into my eyes, and has never once apologised. Management refuses to dim it.

## Run it

```sh
python3 main.py
```

The program checks the line (one line, 1–160 characters), writes it to
`/output/entry.txt`, and prints it.

## Why this review

- **Deadpan throughout:** no winking, no punchline setup — the reviewer is
  genuinely annoyed, which is what makes it funny.
- **Sharpest true grievance:** the sun is too bright, too early, and stares
  straight into your eyes; everyone has felt exactly that.
- **Turns at the end:** "Management refuses to dim it" reframes the sun as
  a badly run service with a customer-service desk that will not help.
- **Tight and specific:** one target, one complaint, no filler words.
